Postiz SemiGod

Herramienta de programación y publicación de contenido de Escobar Inversiones SpA

Qué es

Postiz SemiGod es una instalación propia del software de código abierto Postiz. La usa el equipo de SemiGod Films y de Erick Escobar para programar y publicar contenido (videos, imágenes y textos) en sus propios canales de YouTube, Instagram, Facebook, TikTok y LinkedIn, y para ver estadísticas básicas de esas publicaciones.

A quién está dirigida

Es una herramienta de uso interno. El acceso es solo por invitación. No ofrece registro público ni conecta cuentas de terceros.

Uso de los servicios de API de Google (YouTube)

Postiz SemiGod usa los servicios de la API de YouTube únicamente para subir videos y administrar las publicaciones del canal de YouTube que el propio equipo conecta, y para ver las estadísticas de esos videos. El uso que hacemos de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
